# V17.0.0: Review Studio and verified local deployment

This baseline release contains the complete V1-V17 learning project and its local Review Studio application. It includes browser and JSON API access to durable plan, content, and final review gates, with interactive revision, trusted local retrieval, bounded calculation and conversion tools, and saved session recovery.

## Included

- All V1-V17 Python examples, regression scripts, architecture diagrams, and usage guides.
- V17 asynchronous API and browser interface, session listing, and JSON export.
- Request idempotency, stale review detection, rejection, revision, and restart handling.
- A non-root Docker image recipe, readiness probe, and named-volume storage.
- An exact 43-package dependency baseline and a pinned Python container base digest.
- Windows/Linux and Python 3.12/3.14 CI, plus Docker API and persisted-review integration checks.

## Verification

The release workflow reruns all four offline matrix configurations and the Docker job against the release commit before it creates the tag. Each matrix configuration runs eight scripts: 172 unittest cases across V11-V17 and the V10 assertion-based regression. Docker verifies a pending review survives container replacement unchanged, duplicate decisions preserve state, stale decisions are rejected, and review completes with three approvals, three tool executions, and zero model attempts. The attached release-evidence.json identifies the exact commit and verification run.

## Quick start

Extract the source archive, enter its directory, and create a Python 3.12 or 3.14 virtual environment. On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-v17.lock
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts/ci_checks.py
.\.venv\Scripts\python.exe study_guide_v17_app.py
```

Open http://127.0.0.1:8000. Leave Offline planning checked for a run without model inference. Model planning requires a running Ollama service and the configured local model. See V17_START_HERE.md, docs/V17_GUIDE.md, and docs/RELEASE_GUIDE.md for Docker and platform details.

## Scope and limitations

This is a local, single-user learning application. It has no public multi-user deployment or authentication system. CI covers fixed offline regressions and API integration, not live model quality, semantic entailment, browser automation, or crash-time exactly-once execution. Model output and latency vary. Local databases, learner profiles, and runtime reports are not release assets.

The dependency baseline pins versions without package hashes. The Docker base digest is fixed, while its dependency downloads still require PyPI access. This is a tested version baseline, not a bit-for-bit reproducible build or an automatic security-update service. Supported evidence covers CPython 3.12/3.14 on Windows and Linux x86-64. No prebuilt container image or model weights are published with this release.
